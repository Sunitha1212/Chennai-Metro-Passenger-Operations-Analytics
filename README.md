# Chennai-Metro-Passenger-Operations-Analytics

## Project Overview

This project analyzes Chennai Metro passenger ridership and metro network operations using Microsoft Power BI.

The project combines monthly passenger ridership data with GTFS-based metro network data to understand passenger flow, payment methods, scheduled station activity, routes, trips, and operational patterns.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Data Sources

- Chennai Metro monthly ridership data – OpenCity / CMRL
- Chennai Metro GTFS data – community-maintained GTFS dataset

## Project Workflow

Raw Data
→ Data Understanding
→ Data Cleaning
→ Power Query Transformation
→ Data Modeling
→ DAX Measures
→ Data Visualization
→ Business Insights
